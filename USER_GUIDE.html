C 코드 실행하기

아래에 C 코드를 입력하고 실행해 보세요.

/* 예제: 팩토리얼 함수 */
int factorial(int n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

// main 함수
int main() {
  int result = factorial(5);
  return 0;
}
실행 결과
Hello, World!
Program exiting with code: 0

이 코드는 재귀 함수를 사용하여 팩토리얼을 계산합니다. factorial(5) 호출 시 5 × 4 × 3 × 2 × 1 = 120이 출력됩니다.

  • 재귀 함수: 자기 자신을 호출하는 함수
  • 베이스 케이스: 재귀 종료 조건 (n <= 1)
  • 스택 메모리: 함수 호출 시 쌓이는 메모리
